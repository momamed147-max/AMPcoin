Shared page layout: kill the repeated problems, not one page at a time

Four things repeat across pages, so they are fixed once in ui/page-layout.css
rather than page by page.

1. Duplicated title. The header band already says "Statistics" with the icon and
   the purpose underneath; the page repeated it as an <h1> a few pixels below.
   Two titles saying the same word.

2. Empty panels reserving height. "No finished bets yet" was occupying ~400px,
   so a page with nothing to show looked like a page with a lot to show.

3. Items floating in oversized boxes. Trading's SELLING panel held two small
   tiles in a container sized for a dozen, which reads as missing content rather
   than as a small trade.

4. Panels padded differently on every page, so nothing lined up when moving
   between them.

Two mistakes while doing it, both caught by screenshot rather than by test:

- The empty-state rule used [class*='empty'], which also matched a PANEL whose
  class merely contains that substring, and squashed the whole Recent results
  panel down to a column. Scoped to an actual empty message now.

- Hiding only the h1 left a zero-height wrapper that kept its own positioning,
  so the subtitle escaped upward and overlapped the header band. The whole block
  collapses instead, and the subtitle is re-anchored in normal flow.

415 tests pass across 14 suites.
